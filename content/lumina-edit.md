## Overview

**Lumina Edit** is a high-performance, browser-based image editing tool engineered with vanilla JavaScript, HTML5 Canvas, and CSS3.

Live Application: [Lumina Edit on Vercel](https://image-editor-lovat-eight.vercel.app)

## Highlights

- **Lightroom-Inspired UX**: Seamless image manipulation directly within browser viewports.
- **Pixel-Level Manipulations**: Brightness, saturation, inversion, and blur filters calculated via Canvas pixel arrays.
- **Zero Runtime Dependencies**: Ultra-lightweight initial paint with zero client framework overhead.
