## Overview

A comprehensive ride-sharing application replicating core Uber functionality with real-time socket communication and zero-cost mapping.

GitHub Repository: [MUHAMMADSHAYAN593/Uber-Clone](https://github.com/MUHAMMADSHAYAN593/Uber-Clone)

## Core Architecture

- **Real-Time Booking & Matching**: Custom captain-user matching algorithm coordinating trip requests.
- **OpenStreetMap & Leaflet**: Complete mapping and route rendering without expensive third-party billing.
- **Bidirectional Socket.io**: Live position broadcasts between passenger and driver rooms.
- **Dynamic Fare Engine**: Calculates fares based on distance matrices and route topography.
- **JWT Authentication**: Encrypted credentials with bcrypt and session validation.
