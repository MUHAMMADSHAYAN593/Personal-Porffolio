## Overview

**Student Mental Health Prediction** is a machine-learning web application that estimates student wellbeing indicators using daily lifestyle and behavioral parameters.

Live Deployment: [Student Mental Health Predictor](https://student-mental-health-prediction-jfmm.onrender.com/)

## Features & Indicators Analyzed

- Daily sleep duration
- Study and academic hours
- Social media usage frequency
- Physical activity and exercise metrics
- Self-reported stress levels
- Daily phone unlocks and screen habits

## Architecture

- **Backend**: FastAPI backend serving trained Scikit-Learn regression models.
- **Frontend**: Interactive HTMX + Tailwind CSS interface providing live server-rendered calculations without client-side bundle overhead.
- **Purpose**: Designed as an objective tool for reflection and lifestyle balancing.
