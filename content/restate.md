## Overview

**Restate** is a full-stack real estate mobile application designed with React Native, Expo Router, Express, and MongoDB.

The goal was to move beyond static UI mockups to establish a complete end-to-end data lifecycle: seeding property databases, writing API route handlers, and rendering interactive mobile views.

## Core Capabilities

- **Session Handling**: Demo sign-in authentication flow with session persistence.
- **Database Seeding**: Automated MongoDB seeding scripts for realistic property pricing, addresses, and images.
- **Dynamic Search & Filtering**: Fast category filters, price thresholds, and search indexing.
- **Property Detail Screens**: Full property information including image carousels, agent contacts, and map coordinates.

## Engineering Architecture

- **Client**: Built with React Native and Expo Router, styled with NativeWind for consistent utility-driven design.
- **Backend**: Express API handling property queries, filtering criteria, and authentication boundaries.
