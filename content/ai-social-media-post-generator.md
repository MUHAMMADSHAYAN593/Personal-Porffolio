## Overview

**AI Social Media Post Generator** explores the TanStack Start framework to build a multi-modal content creation tool.

Users enter a short concept (e.g., *"A coffee shop in rain"*), and the system generates a ready-to-post Instagram caption and a matching aesthetic visual instantly.

GitHub Repository: [MUHAMMADSHAYAN593/Social-media-post-generator](https://github.com/MUHAMMADSHAYAN593/Social-media-post-generator)

## Technical Highlights

- **TanStack Start `createServerFn`**: Solved the split-brain problem of modern web apps by keeping client bundles tiny while safely isolating API credentials on the server.
- **Google Gemini API**: Generates witty, engaging, and hashtag-rich captions.
- **Pollinations.ai Integration**: Generates matching visuals on the fly.
- **Real-Time Device Mockups**: Renders output inside authentic social card previews.
