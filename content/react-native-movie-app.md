## Overview

A cross-platform mobile movie application built with **React Native** and **Expo Router** to explore file-based mobile navigation and external API consumption.

## Features

- **Trending & Featured Carousel**: Live updates of trending theatrical releases.
- **Debounced Search**: Real-time title discovery querying TMDB endpoints with minimal re-renders.
- **Comprehensive Movie Dossier**: Detailed budget, box office revenue, release dates, runtime, and production companies.
- **Saved List UI**: Dedicated screens for bookmarking candidate titles.

## Key Learnings

Solving real mobile engineering challenges: handling dynamic route transitions in Expo Router, optimizing remote poster image caching, and structuring reusable mobile card components.
